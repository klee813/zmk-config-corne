# Triage labels

Every triaged issue must have exactly one category label and one workflow-state label.

## Category labels

| Canonical role | GitHub label | Color | Meaning |
|---|---|---|---|
| `bug` | `bug` | `#D73A4A` | Existing behavior is broken |
| `enhancement` | `enhancement` | `#A2EEEF` | New functionality or an improvement |

## Workflow-state labels

| Canonical role | GitHub label | Color | Meaning |
|---|---|---|---|
| `needs-triage` | `needs-triage` | `#FBCA04` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | `#D4C5F9` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | `#0E8A16` | Fully specified and ready for an AI agent |
| `ready-for-human` | `ready-for-human` | `#5319E7` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | `#FFFFFF` | Will not be actioned |

When a skill mentions a canonical role, apply the corresponding GitHub label.
