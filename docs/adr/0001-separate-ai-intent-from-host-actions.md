# Separate AI intent from host actions

The firmware will emit stable semantic signals while a repository-owned Raycast integration translates them into application-specific host actions on macOS; licensed BetterTouchTool is reserved for capabilities Raycast cannot implement reliably. This preserves the portable core and allows AI workflows to evolve without reflashing the keyboard, at the accepted cost of Mac-specific automation configuration and no live agent telemetry on the keyboard OLED.
